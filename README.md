# Лабораторна: нелінійні функції та attention

Відкрийте [attention.ipynb](attention.ipynb) у Jupyter Notebook або JupyterLab.
Усі пояснення, завдання та перевірки містяться в ноутбуці.

Виконуйте комірки послідовно, заповнюйте пропуски `...` і запускайте
перевірки після кожного завдання. Для вправ, які використовують `linear`,
перенесіть свою реалізацію з попередньої лабораторної в комірку ноутбука
перед її першим використанням.

У цій лабораторній ви реалізуєте ReLU, GELU, softmax та attention,
дослідите multi-head attention і вплив нових токенів на ваги уваги.
Наприкінці побудуєте нейронну мережу для XOR із заданими вагами.

Перед здачею перезапустіть ядро й виконайте всі комірки від початку.
Переконайтеся, що перевірки проходять, і додайте відповіді на питання
та результати експериментів у Markdown-комірки. Збережіть готовий ноутбук.
